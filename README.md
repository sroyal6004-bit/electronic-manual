# 📖 메뉴얼함 (Manual Box)

전자제품 **설명서(PDF·사진)** 와 **보증·구매 정보**를 한곳에 보관하는 개인용 PWA.

전자제품을 많이 사다 보면 종이 설명서를 일일이 챙기기 어렵습니다. 제품을 등록하고
사용설명서 PDF·보증서 사진을 첨부해 두면, 필요할 때 폰에서 바로 찾아볼 수 있습니다.

## 주요 기능

- **제품 등록**: 제품명·브랜드·카테고리·모델명·구매일·구매처·메모, 제품 사진
- **설명서 첨부**: PDF 사용설명서, 보증서/영수증 사진 여러 개 첨부 (앱 안에서 바로 열람)
- **보증 관리**: 구매일 + 보증기간으로 만료일 자동 계산, 만료 임박(D-30) 강조
- **검색·필터**: 제품명/브랜드/모델 검색, 카테고리 칩 필터
- **이미지 갤러리 뷰어**: 사진 설명서를 전체화면에서 좌우 스와이프로 열람
- **오프라인 우선**: 네트워크 없이도 완전히 동작 (localStorage + IndexedDB)
- **JSON 백업/복원**: 데이터 내보내기·가져오기(병합)
- **기기 간 동기화(선택)**: 연결 코드 기반 Firebase 동기화 — 폰에서 찍고 데스크탑에서 열람
- **PWA**: 홈 화면에 설치, 다크 테마, 한국어, 뒤로가기(홈에서만 종료), 자동 업데이트

## 구성 (빌드 도구 없음)

- `index.html` — UI·로직·스타일 단일 파일
- `manifest.json` / `sw.js` / `icon-192.png` / `icon-512.png`

GitHub Pages 등 정적 호스팅에 그대로 올리면 됩니다.

## 동기화 켜기 (선택)

기본은 이 기기에만 저장하는 로컬 앱입니다. 여러 기기에서 함께 쓰려면:

1. Firebase 콘솔에서 프로젝트 생성 → Firestore Database + Storage 활성화
2. 웹 앱 등록 후 `firebaseConfig` 값을 `index.html` 상단 `FIREBASE_CONFIG`에 붙여넣기
3. 앱 → 설정(⚙️) → 연결 코드(10자 이상) 입력 → 다른 기기에도 같은 코드 입력

자세한 순서는 앱 안 **설정 → Firebase 연결 안내**에 단계별로 표시됩니다.
